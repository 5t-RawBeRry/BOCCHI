# 4.2.0.8

### New
- Trackers can show Active bronze / Active silver (same bars as Treasure Hunter). Toggle under UI → Trackers.

### Fixes
- The Black Regiment (CE 34) wait area is treated as a square, not a circle
- World → FATEs list no longer clips the progress bar under each FATE
- Active bronze / silver now decrease when you open coffers during a treasure hunt (including Illegal Mode)
- Active bronze / silver clear when you leave Occult Crescent (Trackers and Treasure Hunter)
- Ninja Hide (Treasure Hunt + Carrot Hunt) stays up between nearby strong enemies instead of dropping and sitting on cooldown
- Auto treasure hunt no longer recasts Treasure Sight at session start when the Illegal Mode survey is still fresh
- **Pause auto treasure hunt for CEs** (and FATEs) now pauses Sight hunts reliably — pending triage or camp Sight no longer keeps the route running
