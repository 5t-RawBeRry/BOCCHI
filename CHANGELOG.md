# 4.0.2.25

### New
- Pot timing can skip Magic Pot FATEs by progress % (default 50%) instead of only by minutes left (#174).

### Fixes
- Treasure Hunt no longer loops on the North Horn wind-jump island after giving up on a hard-to-reach coffer (#173).
- After Return to camp for a pot FATE, BOCCHI teleports again instead of mounting across the map (#174).
- Treasure / pot chests can be opened while mounted again (less dying in high Knowledge areas); Crescent Haunt no longer forces Hide (#175).
- Pot treasure farm skips unpathable hint spots instead of standing still until Cache Me expires (#176).
- Illegal Mode no longer Returns away from a pot chest before opening it (next activity was stealing the farm).
